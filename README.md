# Stickly 💬

> A unified messaging platform — chat with friends, and let businesses reach you directly.

## What is Stickly?

Stickly combines personal messaging with business communication in one place.

- 💬 **User-to-User Chat** — Real-time messaging, just like WhatsApp
- 🏢 **Business DMs** — Companies can message their subscribed users directly
- 📦 **Product Updates** — Businesses send updates, offers, and announcements
- 🎧 **Customer Support** — Users connect with company support inside the app
- 🔔 **Subscription-based** — Users choose which businesses to hear from
